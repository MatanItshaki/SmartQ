# SmartQ Frontend

This project was bootstrapped with [Vite](https://vitejs.dev/) and React.

## ספריות עיקריות
- axios (קריאות API)
- react-router-dom (ניווט)
- @mui/material (UI)
- yup + formik (ולידציה וטפסים)
- zustand (state management)

## פקודות
- `npm run dev` — הרצת פיתוח
- `npm run build` — בניית פרודקשן

## התחלה מהירה
1. התקן תלויות: `npm install`
2. הרץ: `npm run dev`
